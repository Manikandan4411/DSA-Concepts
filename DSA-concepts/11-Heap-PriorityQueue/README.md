# Heap and Priority Queue in Java

## Introduction
A heap is a tree-based data structure used to retrieve the highest- or lowest-priority element efficiently.

## Types
- **Min Heap:** The smallest element has the highest priority.
- **Max Heap:** The largest element has the highest priority.
- **Priority Queue:** Processes elements according to priority.

## Files
- `MinHeap.java` – Demonstrates a min-priority queue.
- `MaxHeap.java` – Demonstrates a max-priority queue.
- `priorityqueueBasics.java` – Demonstrates basic priority queue operations.

## Main Operations
- `add()` – Adds an element.
- `peek()` – Views the highest-priority element.
- `poll()` – Removes and returns the highest-priority element.

## Time Complexity
- Add: O(log n)
- Peek: O(1)
- Poll: O(log n)

## Conclusion
Heaps and priority queues are useful for scheduling, task management, and finding minimum or maximum values efficiently.
