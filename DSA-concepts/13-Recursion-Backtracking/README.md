# Recursion and Backtracking in Java

## Introduction
Recursion is when a method calls itself. Backtracking explores possible solutions and returns to try another option when needed.

## Key Concepts
- **Recursion:** Solves a problem by breaking it into smaller problems.
- **Base Case:** Stops the recursive calls.
- **Backtracking:** Tries different choices to find possible solutions.

## File
- `BackTrackingBasics.java` – Prints all subsets of an array using recursion.

## Applications
- Maze solving
- Sudoku solving
- Generating subsets and permutations

## Conclusion
Recursion and backtracking are useful techniques for solving problems that involve exploring different possibilities.
