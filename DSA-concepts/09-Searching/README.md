# Searching Algorithms in Java

## Introduction
Searching algorithms help find a specific element in a collection of data.

## Types of Searching
- **Linear Search:** Checks each element one by one.
- **Binary Search:** Repeatedly divides a sorted array into halves.

## Files
- `LinearSearch.java` – Searches elements one by one.
- `BinarySearch.java` – Searches efficiently in a sorted array.

## Time Complexity

| Algorithm | Time Complexity |
|---|---|
| Linear Search | O(n) |
| Binary Search | O(log n) |

## Important Note
Binary Search requires the array to be sorted.

## Conclusion
Searching algorithms help locate data. Choose the appropriate algorithm based on the data and its arrangement.
