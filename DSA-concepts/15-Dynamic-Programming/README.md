# Dynamic Programming in Java

## Introduction
Dynamic Programming (DP) solves problems by storing results of smaller subproblems to avoid repeated calculations.

## Key Concepts
- **Overlapping Subproblems:** The same subproblems occur repeatedly.
- **Memoization:** Stores results using recursion.
- **Tabulation:** Builds results iteratively using a table or array.

## File
- `DPBasics.java` – Calculates a Fibonacci number using tabulation.

## Time Complexity
- Fibonacci example: O(n)

## Applications
- Fibonacci sequence
- Knapsack problem
- Longest common subsequence
- Shortest path problems

## Conclusion
Dynamic programming can improve efficiency by reusing previously calculated results.
