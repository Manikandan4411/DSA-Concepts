# Greedy Algorithms in Java

## Introduction
A greedy algorithm selects the best available option at each step to solve a problem.

## Key Concepts
- Makes a locally optimal choice at each step.
- Does not always produce the global best solution.
- Works well for problems with the greedy-choice property.

## File
- `GreedyBasics.java` – Demonstrates a coin-selection example using a greedy approach.

## Applications
- Coin change problems
- Activity selection
- Minimum spanning trees
- Scheduling problems

## Conclusion
Greedy algorithms are simple and efficient for suitable problems, but the approach must be verified for each problem.
