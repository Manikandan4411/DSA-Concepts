# Graphs in Java

## Introduction
A graph is a data structure made up of vertices (nodes) and edges (connections).

## Key Concepts
- **Vertex:** A node in the graph.
- **Edge:** A connection between two nodes.
- **BFS:** Visits nodes level by level using a queue.
- **DFS:** Explores a path deeply before backtracking.

## Graph Representation
- **Adjacency List:** Stores each node's neighboring nodes.
- **Adjacency Matrix:** Uses a 2D array to represent connections.

## Files
- `GraphBasics.java` – Creates a simple graph.
- `GraphRepresentation.java` – Demonstrates an adjacency matrix.
- `BFS.java` – Demonstrates Breadth-First Search.
- `DFS.java` – Demonstrates Depth-First Search.

## Time Complexity
- BFS: O(V + E)
- DFS: O(V + E)

Here, V is the number of vertices and E is the number of edges.

## Conclusion
Graphs are useful for representing networks, routes, and relationships between connected objects.
