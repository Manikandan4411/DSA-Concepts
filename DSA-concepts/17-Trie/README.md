# Trie in Java

## Introduction
A Trie is a tree-based data structure used to store and search words efficiently.

## Key Concepts
- **Trie Node:** Stores links to child nodes.
- **Insert:** Adds a word to the Trie.
- **Search:** Checks whether a complete word exists.
- **Prefix:** A beginning part of a word.

## File
- `TrieBasics.java` – Demonstrates inserting and searching for words.

## Time Complexity
For a word of length `L`:
- Insert: O(L)
- Search: O(L)

## Applications
- Autocomplete
- Spell checkers
- Dictionary searches
- Prefix matching

## Conclusion
Tries are useful when searching words and matching prefixes efficiently.
