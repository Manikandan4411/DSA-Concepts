# Bit Manipulation in Java

## Introduction
Bit manipulation performs operations directly on the binary bits of integers.

## Key Operators
- `&` – AND
- `|` – OR
- `^` – XOR
- `~` – NOT
- `<<` – Left shift
- `>>` – Right shift

## File
- `BitManipulationBasics.java` – Demonstrates bitwise operators and basic bit operations.

## Applications
- Checking whether a number is even or odd
- Setting, clearing, and checking bits
- Efficient calculations
- Working with bit flags

## Conclusion
Bit manipulation is useful for solving certain problems efficiently using binary operations.
