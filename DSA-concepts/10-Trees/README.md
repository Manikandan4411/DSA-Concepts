# Trees in Java

## Introduction
A tree is a data structure made up of nodes connected in a hierarchy.

## Key Concepts
- **Root:** The first node in a tree.
- **Parent:** A node that has child nodes.
- **Leaf:** A node without children.
- **Binary Search Tree (BST):** A tree where smaller values go left and larger values go right.

## Tree Traversals
- **Inorder:** Left → Root → Right
- **Preorder:** Root → Left → Right
- **Postorder:** Left → Right → Root

## Files
- `BinarySearchTree.java` – Inserts values into a binary search tree.
- `BinarySearch.java` – Searches a sorted array using binary search.
- `TreeTraversals.java` – Demonstrates three tree traversal methods.

## Time Complexity
- Tree traversal: O(n)
- BST insertion: O(log n) on average, O(n) in the worst case.
- Binary search: O(log n)

## Conclusion
Trees organize data hierarchically and are useful for searching, sorting, and representing relationships.
