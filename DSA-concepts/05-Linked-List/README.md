# Linked List in Java

## Introduction
A linked list is a data structure made up of nodes. Each node stores data and links to other nodes.

## Types of Linked Lists
1. **Singly Linked List:** Each node points to the next node.
2. **Doubly Linked List:** Each node points to the previous and next nodes.
3. **Circular Linked List:** The last node points back to the first node.

## Files
- `singlyLinkedList.java` – Creates and displays a singly linked list.
- `DoublyLinkedList.java` – Creates and displays a doubly linked list.
- `circularLinkedList.java` – Creates and displays a circular linked list.

## Time Complexity
- Traversal: O(n)
- Access by position: O(n)
- Insertion at the beginning: O(1)

## Conclusion
Linked lists store data using connected nodes. They are useful for understanding dynamic data structures and memory links.
